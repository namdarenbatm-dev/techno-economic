# موتور کنترل اقتصادی فروش توسن تکنو — نسخه ۳

این PWA از مدل فریز‌شده «بسته شاپرکی» مستقل است؛ تغییرات این بسته به فایل نسخه فریز‌شده دست نمی‌زند. رابط فارسی، راست‌چین و فونت یکان است.

## قواعد اقتصادی

تمام مبالغ ورودی بر حسب **میلیون تومان** هستند.

- حاشیه ناخالص هر کش‌لس = قیمت فروش مصوب کش‌لس − بهای تمام‌شده جامع کش‌لس
- ظرفیت اقتصادی سفارش = تعداد کش‌لس × (قیمت فروش کش‌لس − بهای تمام‌شده جامع کش‌لس − سود هدف هر کش‌لس) − تعداد کارتخوان × بودجه بازاریابی هر کارتخوان
- تخفیف موردنیاز = تعداد کارتخوان × (قیمت مستقل کارتخوان − قیمت هدف رقابتی)
- سفارش فقط زمانی مجاز است که داده‌ها معتبر، ظرفیت اقتصادی غیرمنفی و ظرفیت اقتصادی حداقل برابر تخفیف موردنیاز باشد.
- اگر هر مقدار کسری وجود داشته باشد، سفارش متوقف است؛ قیمت قابل دستیابی صرفاً برای اصلاح پیشنهاد است و مجوز فروش نیست.
- بودجه مازاد به تخفیف بیشتر تبدیل نمی‌شود. سود هدف کش‌لس و بودجه بازاریابی محفوظ می‌مانند.
- هزینه‌های حمل، نصب و سایر هزینه‌هایی که در بهای تمام‌شده جامع منظور شده‌اند نباید دوباره کسر شوند.

## توضیحات داخل رابط

برای هر فیلد ورودی و بخش اصلی، توضیح کوتاه زیر همان کادر آمده است تا معنای عدد و اثر آن بر محاسبه روشن باشد. نمای کارگزار جزئیات محرمانه مالی را نشان نمی‌دهد. پنل مدیریتی جدول کنترل اقتصادی و سابقه محلی انتخاب سفارش را نمایش می‌دهد.

## قابلیت‌ها

- پنل مدیریت قیمت‌ها و بودجه‌ها
- پیش‌نمایش کارگزار با کنترل توقف سفارش
- جدول کنترل اقتصادی
- خروجی CSV سازگار با Excel
- چاپ/ذخیره PDF از مرورگر
- نصب‌پذیری PWA و کش آفلاین
- ذخیره محلی تنظیمات و سابقه انتخاب روی همان مرورگر
- امکان پاک‌کردن سابقه محلی

## مقادیر نمونه

- قیمت مصوب مستقل کارتخوان: ۲۰ میلیون تومان
- قیمت هدف رقابتی کارتخوان: ۱۵ میلیون تومان
- بهای تمام‌شده جامع کش‌لس: ۲۵ میلیون تومان
- قیمت فروش مصوب کش‌لس: ۴۰ میلیون تومان
- سود هدف هر کش‌لس: ۲ میلیون تومان
- بودجه بازاریابی هر کارتخوان: ۲ میلیون تومان
- ترکیب اولیه: ۵ کارتخوان + ۲ کش‌لس

نتیجه نمونه: ظرفیت اقتصادی ۱۶ میلیون تومان؛ تخفیف لازم ۲۵ میلیون تومان؛ کسری ۹ میلیون تومان. سفارش باید متوقف شود. قیمت ۱۶٫۸ میلیون تومان فقط قیمت محاسباتی برای اصلاح پیشنهاد است.

## نصب و اجرا

برای تست محلی می‌توان از یک سرور استاتیک استفاده کرد، برای مثال: `python -m http.server 8080` در پوشه پروژه و سپس بازکردن `http://localhost:8080`. برای نصب PWA روی گوشی، انتشار HTTPS لازم است.

## محدودیت مهم پیش از بهره‌برداری سازمانی

این نسخه یک PWA سمت کاربر است. تنظیمات و سوابق در همان مرورگر ذخیره می‌شوند و **ذخیره محلی، احراز هویت سازمانی یا سابقه حسابرسی مرکزی نیست**. کاربران می‌توانند داده محلی را تغییر دهند یا پاک کنند. پیش از استفاده عملیاتی در شبکه فروش، باید API سمت سرور، احراز هویت و نقش‌ها، پایگاه داده مرکزی، ثبت تغییرناپذیر رویدادها، نسخه‌بندی مصوبات مالی و اعتبارسنجی مجدد هنگام ثبت سفارش اضافه و روی زیرساخت سازمانی منتشر شود. این بسته به‌تنهایی نباید برای تأیید قطعی سفارش در تولید استفاده شود.
